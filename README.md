📌 Vercel v0 Usage Notes

I used Vercel v0 to generate the initial React/Tailwind UI for the Hero, Features, Testimonials, Pricing, and Footer sections.

I copied these generated components into the Next.js project and converted them into TypeScript components.

I cleaned up the code — removed extra wrapper divs, standardized Tailwind classes, and added proper semantic HTML elements.

I improved responsive behavior using Tailwind breakpoints and fixed spacing, layout, and grid structure manually.

I added consistent CTA button styles, placeholder images, accessibility attributes, and smooth hover transitions.

The project was deployed to Vercel through GitHub integration.
